Reqbox 0.2.0 — the first release with prebuilt binaries. Download the archive
for your platform, unpack it and run `reqbox`; the web client is embedded, so
there is nothing else to install.

## Highlights

- **API token auth.** A random token is generated on first start and printed
  once as a sign-in URL; only its SHA-256 hash is stored. `GET /api/requests`
  used to hand out every stored credential to anyone who could reach the port.
- **The server listens on loopback by default.** Reaching it from another machine
  now takes an explicit `-addr`, and doing so logs a warning.
- **Database permissions are actually restricted on Windows.** `os.Chmod` does
  not touch ACLs there; the file and its `-wal`/`-shm` sidecars now get a real
  DACL limited to the current account.
- **Chinese and English UI**, switchable from the header and remembered across
  reloads.
- **Phased timings** (DNS / connect / TLS / TTFB / download) in the response pane
  and in history.
- **Response tabs reorganised** the way a browser's network panel works:
  Headers, Request Body, Preview, Response — including the headers Reqbox adds on
  your behalf.
- **Long URLs are fully readable**, via a tooltip and an expandable full-URL row.
- **Query parameters in the Params panel win over duplicates in the URL**, instead
  of both being appended.
- **CI on GitHub Actions:** Go tests on Linux and Windows (with the race detector
  on Linux), the front-end suite, and a build that boots the binary to check the
  embedded UI.

## Install

```bash
# Linux / macOS
tar -xzf reqbox_0.2.0_<os>_<arch>.tar.gz
./reqbox
```

Windows archives are `.zip`; unpack and run `reqbox.exe`. On first start the
binary prints an API token and a URL that signs you in.

Verify a download against `checksums.txt`:

```bash
sha256sum -c checksums.txt --ignore-missing
```

## Notes

- Platforms: linux, darwin and windows on amd64 and arm64. `CGO_ENABLED=0`
  throughout — the SQLite driver is pure Go, so no libc is required.
- **Stored credentials are plaintext.** The API token controls who can call the
  API, and the database file is restricted to the account running it, but
  anything that can read that file reads the Bearer tokens, Basic passwords and
  API keys inside it. This is a deliberate scope decision: the tool is meant to
  run on one machine and keep its data there. See `docs/planning/TODO.md` for what
  encryption at rest would take.
- No SSE or WebSocket client yet; HTTP only.
