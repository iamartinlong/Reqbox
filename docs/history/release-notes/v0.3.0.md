Reqbox 0.3.0 — startup no longer depends on being able to copy text out of a
console window. Download the archive for your platform, unpack it, run `reqbox`,
and the browser opens already signed in.

## Highlights

- **The browser opens automatically.** The API token is printed once and never
  again, so anyone who cannot select text in a console window was stuck. Reqbox
  now opens the sign-in link for you: no copying, no pasting. On a restart, where
  the plaintext token is gone, it opens the bare address and you land on the
  unlock screen. `-no-browser` or `server.openBrowser: false` turns it off.

- **`reqbox.yaml` beside the executable.** Previously the listen address could
  only be changed with `-addr` or an environment variable — useless if you start
  the program by double-clicking. Copy `reqbox.example.yaml` to `reqbox.yaml`
  and edit it:

  ```yaml
  server:
    port: 5178        # or `addr: 127.0.0.1:5178`
    autoPort: true    # move to the next free port when this one is taken
    openBrowser: true
  storage:
    db: data/reqbox.db
  auth:
    enabled: true
  logging:
    verbose: false
  ```

  Precedence, highest first: **command-line flag > environment variable >
  `reqbox.yaml` > built-in default**. A file never overrides a flag, so an
  existing shortcut or start script keeps working untouched. Unknown keys are an
  error rather than being ignored, so a typo like `auto_port` fails loudly
  instead of silently doing nothing.

- **A busy port is no longer fatal.** Reqbox tries the next 20 ports and logs
  `requested=... using=...` every time. The sign-in URL and the browser tab use
  the port actually bound. If something depends on an exact port, set
  `server.autoPort: false` to get a clear failure instead.

## Fixes

- **The sign-in URL pointed at port 0** when started with `-addr 127.0.0.1:0`.
  The URL was built from the configured address before the listener existed. It
  is now built from the bound listener, which also makes it correct when the
  server falls back to another port.

- **Selecting text in the Windows console froze the window.** QuickEdit, on by
  default, pauses output when you drag-select and turns Ctrl+C into copy instead
  of interrupt. That flag is cleared at startup.

## Install

```bash
# Linux / macOS
tar -xzf reqbox_0.3.0_<os>_<arch>.tar.gz
./reqbox
```

Windows archives are `.zip`; unpack and run `reqbox.exe`. On first start the
browser opens at a one-time sign-in URL. If it does not, the URL is also printed.

Verify a download against `checksums.txt`:

```bash
sha256sum -c checksums.txt --ignore-missing
```

## Notes

- Platforms: linux, darwin and windows on amd64 and arm64. `CGO_ENABLED=0`
  throughout — the SQLite driver is pure Go.
- **Upgrading is automatic.** The database migrates in place on start: schema
  version 1 (the old `apimock` builds) gains one `history.timing` column, and
  every request, environment, history entry and published mock is kept. Back up
  the file first if you want a way back — the migration has no dry-run mode.
  This was verified against a database produced by the real 2026-10 build,
  including the downgrade direction.
- **Stored credentials are plaintext.** The API token controls who can call the
  API and the database file is restricted to the account running it, but anything
  that can read that file reads the Bearer tokens, Basic passwords and API keys
  inside it. See `docs/planning/TODO.md` for what encryption at rest would take.
- No SSE or WebSocket client yet; HTTP only.
